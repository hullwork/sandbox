# Support

Sandbox Platform is alpha software. Maintainers support the documented SDK, MCP bridge, Control Plane contract, and reference Kubernetes deployment. There is no public-hosting SLA or managed-operations service.

- Reproducible bug: open a GitHub issue with the bug report template.
- Scoped feature or documentation change: open a GitHub feature request.
- Security vulnerability: use GitHub private vulnerability reporting.
- Integration question: include the consumer type, Control Plane URL shape without secrets, SDK/MCP version, and failure response.

Do not attach real tokens, kubeconfigs, workspace files, private prompts, transcripts, or production data.
