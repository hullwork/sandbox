# Maintainers

The current project maintainer is:

- [@convee](https://github.com/convee)

Maintainers review compatibility, security boundaries, releases, and changes to
workspace ownership, credentials, Runtime isolation, storage, and networking.
Routine proposals should use GitHub issues and pull requests. Vulnerabilities must
follow [SECURITY.md](SECURITY.md) and must not be reported in public issues.

Maintainer additions and removals are made by pull request so the repository history
records the decision. Update this file and `.github/CODEOWNERS` together.
